# Игра Мемо
Деплой https://jesenne.github.io/memory-game/

Задание https://github.com/rolling-scopes-school/tasks/tree/master/tasks/memory-game
## Описание приложения
Memory Game — это браузерная игра на поиск пар, реализованная на чистом HTML, CSS и JavaScript без сторонних библиотек и фреймворков для интерфейса и игровой логики.

Игрок открывает карточки и запоминает их расположение, чтобы найти все совпадения за наименьшее число ходов.

## Правила игры
На поле 16 карточек: 8 разных изображений, каждое встречается дважды.

Игра начинается автоматически при первой загрузке и каждой перезагрузке страницы. Все карточки перемешаны и лежат рубашкой вверх, счётчик ходов равен 0, найдено 0 из 8 пар.

Игрок открывает одну карточку, затем другую. Один ход — открытие двух разных доступных карточек, независимо от того, совпали они или нет.

Если изображения совпали, обе карточки остаются открытыми до конца игры, а счётчик найденных пар увеличивается на 1.

Если изображения различаются, обе карточки остаются видимыми примерно секунду (700–1500 мс), затем закрываются. Пока открыта несовпавшая пара, выбрать другие карточки нельзя.

Когда найдены все 8 пар, игра завершается и автоматически открывается модальное окно с сообщением о победе, итоговым числом ходов и кнопками «Новая игра» и «Закрыть».

```
git clone https://github.com/XDobriev/memory-game.git
cd memory-game
git checkout memory-game
```
2. Откройте папку игры в VS Code и запустите index.html через расширение Live Server
